# Trainox

Computer vision dataset studio: label, manage and search your datasets
for object detection and segmentation. Native DICOM / NIfTI support.

🌐 https://trainox.ai


## What you can do
- Label images for object detection and segmentation
- Search a dataset with plain text (e.g. "cat on top of a car")
- Work with medical formats (DICOM / NIfTI) natively
- Automate everything through the API
